
## Структура проекта

```
pokemonbattle_api_tests/
│
├── tests/
│   ├── positive/      # Позитивные тесты
│   └── negative/      # Негативные тесты
│
├── utils/             # Вспомогательные функции
├── conftest.py        # Общие фикстуры
├── pytest.ini         # Настройки pytest
├── requirements.txt   # Зависимости проекта
└── README.md
```

## Почему именно так

Тесты разделены на позитивные и негативные сценарии, что упрощает их запуск и поддержку.

Вспомогательные функции вынесены в `utils`, чтобы избежать дублирования кода.

Общая фикстура `session` находится в `conftest.py`, поэтому она автоматически доступна всем тестам.
